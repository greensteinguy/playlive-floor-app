# v1.5+ backlog

Things that are real ideas but explicitly out of v1 scope. Each item lives here so it doesn't get lost — and so the v1 scope conversation has a clear "yes but not now" home.

> **Discipline:** new ideas go here, not into the v1 SOW. Adding an item is fine. Promoting an item back into v1 requires a Cowork conversation with Guy and an entry in `DECISIONS.md`.

## Format

| Field | What goes here |
|---|---|
| Item | Short name. |
| Description | One sentence. What does this thing do for the user? |
| Why deferred | Why it isn't in v1. |
| Rough size | T-shirt: S / M / L. Best-effort. |
| Depends on | What v1 work needs to land first (if anything). |
| Source | When/where the idea got captured. |
